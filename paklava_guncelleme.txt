BAKLAVA1923 BOT - PAKLAVA GÜNCELLEMESİ

Bu dosya tam bot.py değildir. Mevcut bot.py içindeki ilgili ekonomi bölümünü güncellemek için gereken kod parçalarıdır. Tam bot.py dosyasının geri kalanını görmeden bütün dosyayı yeniden oluşturmak, mevcut komutlarını bozabilir.

1) bot.py içinde OWNER_ID satırının hemen altına bunu ekle:

PAKLAVA_SAHIBI_ID = OWNER_ID
SINIRSIZ_BAKIYE_GOSTERIMI = "∞"

2) Mevcut get_balance, set_balance, add_balance, get_inventory ve get_duel_bonus fonksiyonlarının tamamını aşağıdaki kodla değiştir. Bu kod bakiye ve envanteri sunucudan bağımsız hale getirir.

def get_balance(guild_id, user_id):
    if user_id == PAKLAVA_SAHIBI_ID:
        return 10**18

    cursor.execute(
        "SELECT balance FROM economy WHERE guild_id = 0 AND user_id = ?",
        (user_id,)
    )
    row = cursor.fetchone()

    if row is None:
        # Önceki sunucu bakiyelerini birleştirerek mevcut bakiyeyi korumaya çalış
        cursor.execute(
            "SELECT COALESCE(SUM(balance), 0) FROM economy WHERE user_id = ?",
            (user_id,)
        )
        eski_bakiye = cursor.fetchone()[0]
        bakiye = max(PAKLAVA_BASLANGIC, eski_bakiye)

        cursor.execute(
            "INSERT OR REPLACE INTO economy (guild_id, user_id, balance) VALUES (0, ?, ?)",
            (user_id, bakiye)
        )

def set_balance(guild_id, user_id, new_balance):
    if user_id == PAKLAVA_SAHIBI_ID:
        return

    get_balance(0, user_id)
    cursor.execute(
        "UPDATE economy SET balance = ? WHERE guild_id = 0 AND user_id = ?",
        (max(0, int(new_balance)), user_id)
    )
    db.commit()


def add_balance(guild_id, user_id, amount):
    if user_id == PAKLAVA_SAHIBI_ID:
        return 10**18

    current = get_balance(0, user_id)
    set_balance(0, user_id, current + amount)
    return get_balance(0, user_id)


def get_inventory(guild_id, user_id):
    cursor.execute(
        "SELECT item_key FROM inventory WHERE guild_id = 0 AND user_id = ?",
        (user_id,)
    )
    return [row[0] for row in cursor.fetchall()]


def get_duel_bonus(guild_id, user_id):
    items = get_inventory(0, user_id)
    bonus = 0.0
    for item_key in items:
        item = MARKET_ITEMS.get(item_key)
        if item:
            bonus += item["bonus"]
    return bonus


3) bakiye komutunu aşağıdakiyle değiştir:

@bot.command(name="bakiye", aliases=["cuzdan", "cüzdan"])
async def bakiye(ctx, oyuncu: discord.Member = None):
    hedef = oyuncu or ctx.author
    if hedef.id == PAKLAVA_SAHIBI_ID:
        miktar = SINIRSIZ_BAKIYE_GOSTERIMI
    else:
        miktar = f"{get_balance(0, hedef.id):,}"

    embed = discord.Embed(
        title="Paklava Cüzdanı",
        description=f"{hedef.mention} → **{miktar}** paklava",
        color=discord.Color.orange()
    )
    await ctx.send(embed=embed)

- Paklava sahibi olarak kodda tanımlı OWNER_ID kullanılır. Bu ID'nin sana ait olduğundan emin ol.
- Bu düzenleme bakiye ve envanterin sunucular arasında ortak olmasını sağlar.
- SQLite veritabanı Render'ın geçici diskinde tutuluyorsa yeniden dağıtım veya servis yeniden oluşturma sırasında veriler kaybolabilir. Kalıcılık için Render kalıcı disk veya harici veritabanı gerekir.
